## 1. Machine-Readable Metadata Layers (llms.txt)

The emerging protocol for modern web crawling relies on structured directories placed at your root domain. To guide autonomous research agents, companies must deploy an optimized file framework:

    - llms.txt: Serves as a contextual site map and high-level routing directory for LLM scrapers.
    - llms-full.txt: Provides granular architectural guidelines, processing preferences, and dense information blobs designed specifically for Retrieval-Augmented Generation (RAG) ingestion.
    - AGENTS.md: Dictates execution and tokenprocessing preferences for autonomous processing systems.

Ironically many pundits on Reddit seem to argue about the validity of these terms and protocols directly contradicting what is in Google's very own developer documents. We will stick to what the higher authority has to say about how their systems crawl and index the web.
